# 밸런스 시뮬레이션

설계문서(`docs/`)의 전투·성장·드랍 수치를 코드로 재현해 **초반 성장 속도와 보스 격파 레벨을 사전 예측**하는 도구.
세대 확장(gen2 이상) 시 신규 몬스터·장비·던전 수치를 넣기 전에 이 시뮬레이터로 밸런스를 미리 검증한다.

## 스크립트

| 파일 | 내용 |
|------|------|
| `rpg_sim.py` | 숲 던전 초반 파밍 집중 분석 — 레벨업 곡선, 트렌트 격파확률(레벨별), 목표레벨 도달 비용(포션X/포션O 두 시나리오) |
| `rpg_full.py` | 전체 진행(숲→광산→탑) 분석 — 장비 드랍·스킬 장착·포션·마을 회복 포함, **각 보스 첫 격파 시점 레벨 분포** |

## 실행

```bash
python3 docs/simulation/rpg_sim.py
python3 docs/simulation/rpg_full.py
```

- 외부 의존성 없음 (Python 3 표준 라이브러리만 사용)
- 몬테카를로 방식(기본 수천 회 반복)이라 실행할 때마다 소폭 변동

## 반영된 설계 규칙 (요약)

- 캐릭터 초기 스탯/레벨업 증가량, 레벨업 공식 `반올림(100 × N^1.5)` — `systems/character.md`
- 데미지 공식(물리 방어계수 0.5 / 마법 0.2), 랜덤편차 0.9~1.1, 치명타 `5% + 속도×0.2% + 치명타%`, ×1.5 — `systems/combat.md`
- 마을 복귀 시 HP/MP 전량 회복, 전투 종료 시 MP 100% — `systems/combat.md`
- 던전 이벤트 확률(전투 75 / 휴식 8 / 상인 7 / 함정 5 / 보물 5), 함정 −현재HP10% / 휴식 +최대HP10% — `systems/dungeon.md`
- 2축 파워 모델: 등급→슬롯·능력치 개수, 유효레벨 P=itemLevel+등급보너스 → 기본공격력·수치 스케일 — `systems/items-grades.md`
- 드랍: 일반몹 방어구 5%, 보스 무기/스킬북 각 15%(상호배타), 던전 `gradeChance`로 등급 롤 — `systems/farming.md`
- 세대1 몬스터/무기/스킬/던전 수치 — `generations/gen1/`

## 주요 전제(한계)

- `rpg_full.py`는 **메인 무기를 검(SWORD)으로 고정**하고 검 무기가 드랍될 때만 업그레이드한다(보수적). 실제 플레이는 더 강한 타입·등급 무기를 유연하게 채택하므로 **실제 격파 레벨은 시뮬보다 낮게(더 이르게)** 나올 수 있다.
- 세대1은 무기 타입별 스킬이 1종뿐이고 중복 장착이 불가하므로, 무기는 사실상 `기본공격 + 해당 타입 스킬 1개`로 모델링된다.
- 포션은 전투 중 HP<35%에서 사용, 마을에서 최대 6개까지 보충한다고 가정한다.

## 현재(세대1) 검증 결과 스냅샷

- 트렌트(권장1): 첫 격파 중앙 Lv2
- 광산왕(권장5): 첫 격파 중앙 Lv7 (25~75%: Lv6~7)
- 흑마도사(권장10): 첫 격파 중앙 Lv11 (25~75%: Lv10~12)

> 세대2 추가 시: `MON`/`DUNGEONS`/`GRADE_*` 등 상수에 신규 수치를 넣고 목표 격파창을 재설정해 검증한다.
