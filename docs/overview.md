# 개요

## 게임 정보

- **장르**: 텍스트 기반 턴제 RPG
- **플랫폼**: 모바일 웹 (출퇴근 시 10~20분 세션)
- **대상**: 1인 플레이 (싱글)
- **수익화**: 없음 (개인 취미 프로젝트)
- **기술 스택**: Spring Boot + Thymeleaf (`myrpg` 모듈)
- **현재 범위**: 세대 1 (레벨 1~10)

---

## 핵심 컨셉

> 직업 없음 → 무기가 곧 빌드 → 스킬북 드랍으로 무기에 스킬 장착 → 무기 등급이 스킬 슬롯 수 결정

무기를 바꾸면 플레이 스타일이 완전히 달라지는 구조.

---

## 게임 루프

```
[마을]
  ├─ 던전 선택 → 전투 시작 (장비는 마을에서 미리 세팅)
  ├─ 장비 관리 (무기/방어구 착용·교체, 스킬북 장착)
  ├─ 상점 (전리품 판매 · HP/MP 포션 구매)
  └─ 캐릭터 정보 (스탯, 보유 무기 목록)
```

> **장비/무기 교체는 마을에서만 가능**. 던전 진입 후에는 무기·방어구 변경 불가.

### 던전 1회 흐름

```
[마을] → [던전 선택] → [탐색 (스테이지 전투 반복)] → [보스] → [보상] → [마을 복귀]
```

- 던전 1회 클리어: 5~15분 이내 목표
- 모든 던전은 5스테이지 고정 (1~4 일반몹, 5 보스) — `systems/dungeon.md` 참고

---

## 전략적 재미 포인트

1. **무기 = 빌드**: 무기를 바꾸면 완전히 다른 플레이
2. **스킬북 긴장감**: 한 번 장착하면 빼면 소멸 → 신중한 선택
3. **무기 2개 운영**: 몬스터 특성(고방어 물리형 vs 저방어 고속형)에 따라 무기 전환 — 예) 방어력 높은 골렘/가고일 상대엔 고배율 스킬(도끼·창)이나 방어력을 우회하는 마법(지팡이)이 유리
4. **파밍 동기 (등급·롤 로또)**: 어느 던전이든 전 등급이 나올 수 있어 "완벽한 롤" 추격이 끝없음
5. **던전 선택 전략**: 같은 세대 던전은 모두 같은 장비를 드랍하되, 상위 던전일수록 고등급 확률(`gradeChance`)과 수치 크기(`itemLevel`)가 높다
6. **골드 순환**: 필요 없는 전리품을 상점에 팔아 HP/MP 포션 구매 자금으로 순환
