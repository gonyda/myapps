# 무기 & 스킬 시스템

세대 무관 공통 규칙. 무기 카테고리와 스킬 장착 규칙을 정의한다.
(등급·파워 모델·랜덤 능력치는 `systems/items-grades.md`, 세대1 실제 무기/스킬 목록은 `generations/gen1/`)

## 무기 카테고리 (6종)

무기 타입은 **데미지 타입 + 타입 고유 속도/치명타 보너스**로 개성이 갈린다. 속도는 선/후공과 치명타 확률 양쪽에 영향을 주므로(`systems/combat.md`), 타입별 플레이 감각이 실제로 달라진다.

| 무기 | 데미지 타입 | 속도 | 치명타 | 메커니즘상 특징 |
|------|------------|-----:|------:|----------------|
| 검(Sword) | 물리 | +2 | +2 | 밸런스 — 무난한 선공·치명 |
| 도끼(Axe) | 물리 | −3 | 0 | 최고 공격력, 속도 페널티로 후공이 잦음 (맞고 시작, 한 방이 큼) |
| 창(Spear) | 물리 | +3 | +1 | 준수한 공격력 + 약간의 선공 우위 |
| 단검(Dagger) | 물리 | +6 | +8 | 기준 공격력은 최저지만 거의 항상 선공 + 높은 치명타로 딜 보완 |
| 지팡이(Staff) | 마법 | +1 | +1 | 유일한 마법 — 방어력을 덜 받아 고방어 몬스터에 강함 |
| 활(Bow) | 물리 | +5 | +4 | 원거리 — 안정적 선공과 준수한 치명타 |

- 위 속도/치명타는 무기 템플릿의 **고정값**(`baseSpeed`/`baseCritical`)으로, 착용 시 캐릭터 스탯에 합산된다. 실제 수치는 `generations/gen1/weapons.md`
- 무기는 스킬 컨테이너 역할도 하며, 등급이 스킬 슬롯 수를 결정한다 (`systems/items-grades.md`)

## 스킬 시스템

스킬은 데미지 배율(+MP 소모)만 가진다. 쿨다운·상태이상 없음.

### 핵심 규칙

1. **스킬북은 1회용** — 사용하면 소모됨
2. **스킬북은 무기에 종속** — 장착하면 해당 무기에 귀속
3. **스킬 덮어쓰기 시 기존 스킬 영구 소멸** — 신중한 선택 강요
4. **동일 스킬 중복 장착 불가** — 다양한 조합 유도
5. **무기 간 스킬 이동 불가** — 무기 자체가 완성된 빌드
6. **스킬은 무기 종류에 종속** — 검 스킬은 검에만 장착 가능

### 스킬북 사용 흐름

```
1. 몬스터 처치 → 스킬북 드랍
2. 인벤토리에서 스킬북 사용
3. 해당 무기 종류의 무기 중 선택
4. 무기의 빈 슬롯에 스킬 장착
5. 스킬북 소모됨
```

### 스킬 속성

| 필드 | 설명 |
|------|------|
| weaponType | 이 스킬을 장착할 수 있는 무기 종류 |
| damageType | PHYSICAL(물리) / MAGICAL(마법) — 데미지 공식 결정 (`systems/combat.md`) |
| damageMultiplier | 데미지 배율 (기본공격 = 1.0, 스킬 0.8~2.0) |
| mpCost | 사용 시 MP 소모량 |

> 세대1의 실제 스킬 6종은 `generations/gen1/skills.md` 참고.
