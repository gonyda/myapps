# 화면 구성 (모바일 최적화)

세대 무관 공통 UI. 텍스트 기반 모바일 화면 목업.

## 디자인 원칙

| 원칙 | 내용 |
|------|------|
| 한 손 조작 | 하단 버튼 중심, 엄지로 모든 조작 |
| 텍스트 가독성 | 큰 폰트, 충분한 행간 |
| 최소 스크롤 | 한 화면에 필요한 정보 모두 표시 |
| 이모지 활용 | 그래픽 없이 직관적 아이콘 |
| 다크 모드 | 출퇴근 시 눈 피로 감소 |

## 화면 흐름 요약

```
마을
 ├─ 🎒 장비 → [방어구 탭] 착용/해제
 │           → [무기 탭] 착용/해제, 스킬북 장착
 ├─ 🏔️ 던전 → 던전 선택 → 바로 입장 → 탐색/전투 반복 → 보스 → 마을
 ├─ 🏪 상점 → [판매 탭] 전리품 판매 → [구매 탭] HP/MP 포션 구매
 └─ 👤 정보 → 스탯 확인
```

던전 입장 시 별도 장비 선택 화면 없음 — 마을에서 미리 세팅한 장비로 바로 진입.
**권장레벨은 안내일 뿐 입장 제한이 아니다** — 어떤 던전이든 자유롭게 입장할 수 있다.

## 화면 5: 던전 탐색 (스테이지 진입 이벤트)

각 스테이지 진입 시 이벤트가 랜덤 결정된다 (분기 선택 없음, 순차 진행). 아래는 비전투 이벤트(보물상자) 예시.

```
┌─────────────────────────────┐
│  ⛏️ 광산 던전  3스테이지/5    │
├─────────────────────────────┤
│  HP ████████░░░░ 80/150     │
│  MP ██████████░░ 60/80      │
├─────────────────────────────┤
│  갱도 구석에서 낡은 상자를   │
│  발견했다.                  │
│  🎁 보물상자!               │
│  💰 48 Gold 를 얻었다.      │
├─────────────────────────────┤
│  ┌─────────────────────────┐│
│  │     다음 스테이지로 →    ││
│  └─────────────────────────┘│
│  ┌─────────────────────────┐│
│  │   🚪 포기하고 마을로     ││
│  └─────────────────────────┘│
└─────────────────────────────┘
```

- 전투 이벤트면 → 화면 6(전투)으로 진입
- 휴식(최대 HP +10%) / 함정(현재 HP −10%) / 상인(상점과 동일) / 보물상자 이벤트는 결과를 보여준 뒤 `다음 스테이지로` 버튼으로 진행
- **던전 포기**: 스테이지 사이에서 `포기하고 마을로`로 페널티 없이 복귀 (진행 삭제, 다음엔 처음부터 — 파밍 경로, `systems/dungeon.md`)
- 이벤트 종류·확률은 `systems/dungeon.md` 참고

## 화면 7: 전투 승리 / 드랍

```
┌─────────────────────────────┐
│  🎉 전투 승리!               │
├─────────────────────────────┤
│  동굴 박쥐를 처치했다!      │
│  ┌─────────────────────────┐│
│  │ 📊 결과                  ││
│  │ 경험치: +48 (120/283)   ││
│  │ 골드: +22               ││
│  └─────────────────────────┘│
│  ┌─────────────────────────┐│
│  │ 🎁 드랍 아이템           ││
│  │ 🧤 낡은 장갑 [일반]      ││
│  │    방어력 +3             ││
│  └─────────────────────────┘│
│  ┌─────────────────────────┐│
│  │   다음 스테이지로 →      ││
│  └─────────────────────────┘│
│  ┌─────────────────────────┐│
│  │   🚪 포기하고 마을로     ││
│  └─────────────────────────┘│
└─────────────────────────────┘
```

- 전투 승리 시점에 해당 스테이지는 **클리어로 처리**되어 경험치·골드·드랍·체크포인트가 이미 반영된다
- 따라서 `포기하고 마을로`를 눌러도 이번 런에서 획득한 것은 모두 유지된 채 페널티 없이 마을로 복귀한다 (진행 삭제, 다음엔 처음부터 — `systems/dungeon.md`)
- 5스테이지(보스) 승리 시에는 던전이 완전 클리어되어 자동으로 마을로 복귀하므로 포기 버튼은 표시되지 않는다
