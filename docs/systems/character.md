# 캐릭터 시스템

세대 무관 공통 규칙. 캐릭터의 성장·스탯·페널티를 정의한다.

## 성장 축

| 축 | 내용 |
|---|---|
| 레벨 | 전투 경험치 → 스탯 자동 증가 (HP/MP/공/방/속/치명타) |
| 무기 수집 | 더 높은 등급 = 더 많은 스킬 슬롯 + 랜덤 능력치 |
| 스킬 수집 | 스킬북 드랍으로 무기 강화 |
| 방어구 | 랜덤 능력치 5종(방어력/체력/속도/공격력/치명타) 보정 |

## 캐릭터 특성

- **직업 없음** — 무기 선택이 곧 빌드
- 레벨업 시 스탯 자동 성장 (별도 배분 없음)

## 레벨업 공식

```
레벨 N → N+1 필요 경험치 = 반올림(100 × N^1.5)
```

| 레벨 | 다음 레벨까지 필요 경험치 (누적 아님) |
|------|--------------------------------------|
| 1 → 2 | 100 |
| 2 → 3 | 283 |
| 3 → 4 | 520 |
| 4 → 5 | 800 |
| 5 → 6 | 1,118 |
| 10 → 11 | 3,162 |

## 초기 스탯 (Lv.1)

| 스탯 | 값 |
|------|-----|
| HP | 100 |
| MP | 50 |
| 공격력 | 10 |
| 방어력 | 5 |
| 속도 | 5 |
| 치명타 | 0 |

## 레벨업 시 증가량 (레벨당)

| 스탯 | 증가량 |
|------|--------|
| HP | +20 |
| MP | +10 |
| 공격력 | +3 |
| 방어력 | +2 |
| 속도 | +1 |
| 치명타 | +1 |

- 레벨업 시 HP/MP 전량 회복
- 위 값은 순수 캐릭터 기본 스탯이며, 장비 능력치는 여기에 합산

## 시작 지급 (신규 캐릭터)

무기·스킬북은 보스 드랍이 주 획득 경로이므로, 신규 캐릭터가 첫 진행을 시작할 수 있도록 아래를 기본 지급한다.

| 항목 | 내용 |
|------|------|
| 시작 무기 | `[일반] 낡은 검` (SWORD, COMMON, itemLevel 1) — 착용 상태로 지급 |
| 시작 골드 | 0 Gold |

- 시작 무기는 슬롯 1칸·능력치 1개짜리 최소 사양이며, 이후 던전 드랍으로 교체·강화한다.
- 이 지급 규칙 덕분에 "무기가 없어 보스를 못 잡고, 보스를 못 잡아 무기가 안 나오는" 순환이 발생하지 않는다.

## 사망 / 도망 / 이탈 페널티

| 상황 | 페널티 | 진행 상태 | 결과 |
|------|--------|----------|------|
| 던전 내 사망 (HP 0) | 현재 경험치 **10% 감소** | **삭제** (재개 불가) | 마을로 복귀 |
| 명시적 도망 (전투 중 도망 성공) | 현재 경험치 **5% 감소** | **삭제** (재개 불가) | 마을로 복귀 |
| 던전 포기 (스테이지 사이 자발적 복귀) | **없음** | **삭제** (재개 불가) | 마을로 복귀 |
| 웹 종료 / 세션 끊김 | 없음 | **유지** (체크포인트 재개) | 다음 접속 시 이어하기 |

- **경험치 감소 방식**: 누적 경험치가 아니라 **현재 레벨에서 보유 중인 현재 경험치(레벨 내 진행분)에만** 퍼센트를 적용해 감소한다. **레벨 다운은 발생하지 않으며**, 현재 경험치가 0이면 감소량도 0이다.
  - 예) Lv.5, 현재 경험치 500 보유 중 사망 → 500 × 10% = 50 감소 → 450으로 조정 (레벨 유지)
- **사망 / 명시적 도망**: 경험치 페널티 + 진행 상태(체크포인트) 삭제 → 다음에는 해당 던전을 처음부터 시작
- **던전 포기**: 스테이지 사이(전투 중 아님)에 자발적으로 마을 복귀. **경험치 페널티 없음**, 진행 상태는 삭제되어 다음엔 처음부터. 보스 없이 스테이지 1~4만 반복해 안전하게 경험치·전리품을 파밍하는 경로다 (`systems/dungeon.md`)
- **웹 종료(비정상 이탈)**: 페널티 없음, 마지막 완료 스테이지 다음부터 재개 (`systems/dungeon.md` 참고)
- 위 모든 경우 그때까지 획득한 아이템은 유지 (경험치만 페널티가 있는 사망/도망 포함)
