# 던전 시스템

세대 무관 공통 규칙. 던전 구조와 진행 상태 저장을 정의한다.
(세대1 실제 던전 3개는 `generations/gen1/dungeons.md`)

## 던전 구조

```
던전 = { 이름, 난이도, 스테이지수(=5 고정), 등장몬스터풀[], 보스, gradeChance, treasureBaseGold }
```

- **모든 던전은 5스테이지 고정** — 1~4스테이지는 일반몹, 5스테이지는 보스
- 스테이지 진행은 순차적 (1 → 2 → 3 → 4 → 5), 각 스테이지 클리어 시 다음 스테이지로 진행

## 층별(스테이지) 이벤트 (랜덤)

각 스테이지(1~4)에 진입하면 아래 확률로 이벤트가 하나 결정된다. **5스테이지는 항상 보스 전투 고정**이다.
분기(갈림길) 선택은 없으며, 스테이지는 순차적으로만 진행한다.

| 이벤트 | 확률 | 효과 |
|--------|------|------|
| 전투 | 75% | 일반 몬스터와 전투 (경험치·골드·드랍은 **전투에서만** 발생) |
| 휴식 | 8% | **최대 HP의 10% 회복** (최대치 초과 없음) |
| 상인 | 7% | 마을 상점과 동일 (전리품 판매 + HP/MP 포션 구매, `systems/shop.md`) |
| 함정 | 5% | **현재 HP의 10% 감소** (최소 HP 1 보장, 함정으로 사망하지 않음) |
| 보물상자 | 5% | 보상 획득 (아래 참고) |

- 확률 합 = 100%. 비전투 이벤트는 경험치·드랍을 주지 않으므로 전투 비중을 75%로 유지한다.
- 비전투 이벤트 스테이지도 **완료 즉시 체크포인트 저장** 대상이다 (전투와 동일하게 "스테이지 클리어"로 처리).

### 보물상자 보상 (내부 롤)

보물상자는 아래 확률로 보상 종류를 한 번 더 롤한다.

| 보상 | 확률 | 내용 |
|------|------|------|
| 골드 | 50% | `반올림(기본골드 × (1 + 0.05 × itemLevel))` — 던전 권장레벨 비례 |
| 포션 | 40% | HP 포션 또는 MP 포션 (균등) 1개를 인벤토리에 지급 |
| 장비 | 10% | 해당 던전 `gradeChance`로 등급 롤한 무기/방어구 1개 (`systems/farming.md`) |

- `기본골드`는 세대1 값으로 `generations/gen1/dungeons.md`에서 정의 (또는 던전 설정)
- 장비 보상은 일반 전투 드랍과 동일한 등급·능력치 롤 규칙을 따른다

## 진행 상태 저장 (스테이지 체크포인트)

던전 진행은 **스테이지 단위 체크포인트**로 저장된다. 진행 중인 상태는 서버 DB에 영속화되어, 웹을 껐다 켜도 이어서 진행할 수 있다. (DB: `rpg_player_active_run`, `systems/persistence.md`)

### 저장 시점

- **각 스테이지가 종료(클리어)되는 순간** 진행 상태를 저장한다
- 저장 내용: 던전 id, **마지막으로 완료한 스테이지 번호**, 그 시점의 플레이어 HP/MP, 지금까지 획득한 아이템(이미 인벤토리에 반영됨)
- 스테이지 **진행 중(전투 중)** 상태는 저장하지 않는다 (HTTP 세션에만 존재)

### 재개 규칙

- 진행 중이던 던전이 있으면 **마지막으로 완료한 스테이지의 다음 스테이지 처음부터** 재개한다
- 재개 시 HP/MP는 마지막 체크포인트 값으로 복원 (MP는 전투 종료 시 100% 회복 규칙에 따라 사실상 최대치)

### 예시

```
스테이지 1 클리어 → 저장 (완료=1)
스테이지 2 클리어 → 저장 (완료=2)
스테이지 3 진행 중 웹 종료  → 저장 안 됨 (완료=2 유지)
────────────────────────────────
재접속 → 스테이지 3 처음부터 재개 (스테이지 2 종료 시점 HP/MP)
```

> **웹 종료(세션 끊김) ≠ 도망**: 단순 이탈/세션 만료는 경험치 페널티가 없으며 체크포인트에서 재개된다.
> 반면 **사망(HP 0)** 과 **명시적 도망**은 경험치 페널티 + 진행 상태 삭제(재개 불가, 처음부터)로 처리된다 (`systems/character.md`).
> (알려진 트레이드오프: 위기 상황에서 웹을 꺼서 스테이지를 다시 시도하는 회피가 가능하나, 싱글 취미 프로젝트 특성상 허용한다.)

## 던전 포기 (중도 복귀 / 파밍 경로)

플레이어는 **스테이지 사이(전투 승리 직후 결과 화면, 또는 비전투 이벤트 화면 등 전투 중이 아닐 때)** 언제든 던전을 포기하고 마을로 돌아올 수 있다.

- **경험치 페널티 없음**, 그때까지 획득한 아이템·경험치는 모두 유지
- 진행 상태(`rpg_player_active_run`)는 삭제되어 다음에는 해당 던전을 **처음(1스테이지)부터** 시작
- **전투 중에는 포기 불가** — 전투에서 벗어나려면 `도망`(50% 확률, 5% 경험치 페널티)만 가능
- **파밍 경로**: 보스를 상대하기 버거운 초반에는 스테이지 1~4에서 전투로 경험치·전리품을 모은 뒤, 5스테이지(보스) 직전에 포기해 안전하게 마을로 복귀하며 반복 성장할 수 있다

> 초반 데스루프(첫 캐릭터가 보스를 못 잡아 사망 페널티만 누적되는 문제)를 방지하기 위한 안전한 성장 수단이다.
