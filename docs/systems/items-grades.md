# 장비 · 등급 · 파워 모델

세대 무관 공통 규칙. **무기와 방어구 모두 동일한 등급/파워 모델**을 따른다.
(세대1 실제 무기/방어구 템플릿은 `generations/gen1/weapons.md`, `generations/gen1/armors.md`)

## 등급 (5단계)

| 등급 | 영문 |
|------|------|
| 일반 | COMMON |
| 고급 | UNCOMMON |
| 희귀 | RARE |
| 영웅 | EPIC |
| 전설 | LEGENDARY |

- **등급은 템플릿 고정이 아니라 드랍 순간에 롤**된다 (던전 `gradeChance`, `systems/farming.md`)
- 인스턴스 이름은 `[등급] 템플릿명` 형식으로 표기 (예: `[전설] 낡은 검`, `[일반] 가죽 투구`)

## 장비 슬롯 (총 5칸)

| 슬롯 | 장비 종류 | 역할 |
|------|----------|------|
| 머리 | 투구(HELMET) | 방어구 (랜덤 능력치) |
| 몸통 | 갑옷(CHEST) | 방어구 (랜덤 능력치) |
| 손 | 장갑(GLOVES) | 방어구 (랜덤 능력치) |
| 발 | 신발(BOOTS) | 방어구 (랜덤 능력치) |
| 무기 | 무기 | 스킬 컨테이너 (기본공격력 + 타입 고유 속도/치명타 + 스킬슬롯 별도) |

## 2축 파워 모델

성능은 **두 축**으로 결정된다. 등급은 "구조"(슬롯·능력치 개수), 유효 파워 레벨은 "수치 크기"를 담당한다.

### 축 1 — 등급 → 구조 (스킬슬롯 + 능력치 개수)

| 등급 | 스킬슬롯(무기) | 랜덤 능력치 개수 |
|------|--------------|-----------------|
| COMMON | 1 | 1개 |
| UNCOMMON | 2 | 1~2개 |
| RARE | 3 | 2~3개 |
| EPIC | 4 | 3~4개 |
| LEGENDARY | 5 | 4~5개 |

- 방어구는 스킬슬롯이 없고 랜덤 능력치 개수만 등급으로 결정된다.

### 축 2 — 유효 파워 레벨 → 수치 크기

- **itemLevel** = 드랍된 던전의 권장레벨 (1 / 5 / 10 / …), 인스턴스에 저장
- **등급 레벨 보너스**: COMMON +0 / UNCOMMON +2 / RARE +5 / EPIC +8 / LEGENDARY +10
- **유효 파워 레벨 P = itemLevel + 등급 레벨 보너스**
- **기본공격력(무기, 실제) = 반올림(기준공격력 × (1 + 0.15 × P))**
- **능력치 수치 = [최대(1, 반올림(P×0.4)) ~ 반올림(P×0.8)]** 범위에서 랜덤

> 무기의 **타입 고유 스탯(baseSpeed / baseCritical)**은 이 스케일과 무관한 **고정값**이다. 착용 시 캐릭터 속도·치명타에 그대로 합산되어 무기 타입의 개성을 만든다 (값은 `generations/gen1/weapons.md`, 합산 규칙은 `systems/combat.md`).

> 효과: 전설(+10)은 드랍한 던전보다 **약 10레벨 위 콘텐츠까지 무리없이 쓸만한** 수준으로 스케일된다.
> 예) 숲(itemLevel 1) 전설 ≈ 탑(Lv10) 일반, 탑(itemLevel 10) 전설 ≈ Lv20 일반.

| 유효레벨 P (예) | 수치 범위 |
|-----------------|----------|
| 1 (숲 일반) | 1~1 |
| 11 (숲 전설) | 4~9 |
| 15 (탑 희귀) | 6~12 |
| 20 (탑 전설) | 8~16 |
| 30 (Lv20 전설) | 12~24 |

## 랜덤 능력치

### 부여 가능 능력치 (5종)

| 능력치 | 효과 |
|--------|------|
| 방어력 | 받는 물리 데미지 감소 |
| 체력(HP) | 최대 HP 증가 |
| 속도 | 선/후공 판정 및 치명타 확률에 영향 |
| 공격력 | 기본 공격 및 스킬 데미지 증가 |
| 치명타 | 치명타 확률 직접 증가 |

- 부여될 능력치 종류는 5종 중 무작위 선택 (**중복 없음**)
- 능력치 **개수**는 등급, **수치 크기**는 유효 파워 레벨로 결정

### 동시 부여 확률 (등급별)

| 등급 | 1개 | 2개 | 3개 | 4개 | 5개 |
|------|-----|-----|-----|-----|-----|
| COMMON | 100% | - | - | - | - |
| UNCOMMON | 60% | 40% | - | - | - |
| RARE | - | 60% | 40% | - | - |
| EPIC | - | - | 60% | 40% | - |
| LEGENDARY | - | - | - | 50% | 50% |

## 인스턴스 데이터 구조

무기는 기본공격력 + 스킬슬롯을 추가로 가진다. 방어구는 기본 스탯 없이 랜덤 능력치로만 성능이 결정된다.

```
무기 인스턴스 = {
  템플릿: 낡은 검, 종류: SWORD,
  등급: RARE,              // 드랍 시 롤
  itemLevel: 10,           // 드랍된 던전 권장레벨 → P = 10 + 5 = 15
  스킬슬롯: 3,             // 등급에서 파생
  기본공격력: 33,          // 반올림(10 × (1 + 0.15 × 15))
  기본속도: 2, 기본치명타: 2,   // 타입 고유 고정값 (SWORD)
  장착스킬: [강타, null, null],
  랜덤능력치: [ {공격력, 10}, {치명타, 8} ]   // 개수=등급, 수치=유효레벨 스케일
}

방어구 인스턴스 = {
  템플릿: 강철 갑옷, 부위: CHEST,
  등급: RARE, itemLevel: 10,
  랜덤능력치: [ {방어력, 9}, {체력, 11}, {속도, 7} ]
}
```

## 드랍 예시

```
[일반] 가죽 갑옷        → 방어력 +3
[희귀] 강철 갑옷        → 방어력 +9, 체력 +11, 속도 +7
[전설] 용비늘 갑옷      → 방어력 +18, 체력 +15, 속도 +14, 공격력 +16, 치명타 +13
[희귀] 사냥꾼의 활      → 기본공격력 22 / 스킬슬롯 3 / 속도 +8, 치명타 +5
```

> 드랍 판정(카테고리·등급 롤)과 파밍 모델은 `systems/farming.md`, 판매가는 `systems/shop.md` 참고.
