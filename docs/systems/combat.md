# 전투 시스템

세대 무관 공통 규칙. 턴제 전투의 규칙과 계산식을 정의한다.

## 기본 규칙

- **턴제** 방식
- **선/후공**: 속도 스탯으로 결정
- **무기 교체**: 마을에서만 가능 (던전 진입 후 및 전투 중 불가)
- **MP 회복**: 전투 종료 시 MP 100% 자동 회복 (매 전투 풀충전 시작)
- **마을 복귀 시 HP/MP 전량 회복**: 던전 클리어·포기·사망·도망 등 어떤 경로로든 마을로 돌아오면 HP와 MP가 최대치로 회복된다. 던전 내부에서만 HP를 관리하면 되며, 마을에서 다음 던전을 온전한 상태로 시작한다.

## 전투 스탯 합산 (유효 스탯)

전투에 쓰이는 스탯은 **캐릭터 기본 스탯 + 착용 무기 + 착용 방어구**를 모두 합산한 값이다.

```
유효 공격력   = 캐릭터 공격력 + 무기 기본공격력 + 장비 랜덤 공격력
유효 속도     = 캐릭터 속도   + 무기 baseSpeed    + 장비 랜덤 속도
유효 치명타   = 캐릭터 치명타 + 무기 baseCritical + 장비 랜덤 치명타
유효 방어력   = 캐릭터 방어력 + 장비 랜덤 방어력
유효 최대 HP  = 캐릭터 최대 HP + 장비 랜덤 체력
```

- **무기 `baseSpeed`/`baseCritical`**은 타입 고유 고정값이며, 선/후공 판정과 치명타 확률에 직접 반영된다 (`systems/weapons-skills.md`, `generations/gen1/weapons.md`)
- 방어구는 기본 스탯이 없고 랜덤 능력치로만 기여한다 (`systems/items-grades.md`)
- 아래 데미지·치명타·선후공 공식의 "공격력/속도/방어력/치명타"는 모두 **유효 스탯**을 의미한다

## 전투 행동

```
기본공격  — 항상 가능, 무기 기본 데미지
스킬 1~N  — 무기에 장착된 스킬, MP 소모
아이템 사용 — 포션 등 (1턴 소모)
도망      — 50% 고정 확률 (성공 시 마을 복귀·도망 페널티, 실패 시 턴 소모 후 적 반격)
```

## 턴 구조

```
1. 속도 스탯으로 선/후공 결정
2. 플레이어 행동 선택
3. 적 행동 (AI 패턴)
4. 전투 종료 판정
5. 반복
```

## 데미지 계산식

### 기본 데미지

```
물리 데미지 = (공격력 × 스킬배율 - 방어력 × 0.5) × 랜덤편차
마법 데미지 = (공격력 × 스킬배율 - 방어력 × 0.2) × 랜덤편차
```

- **데미지 타입**: 기본공격과 스킬의 `damageType`(PHYSICAL/MAGICAL)으로 결정
  - 지팡이(STAFF)의 기본공격·스킬은 MAGICAL, 그 외 무기는 PHYSICAL
- **방어력 계수**: 물리 0.5 / 마법 0.2 — 마법은 방어력을 덜 받으므로 고방어 몬스터에 상대적으로 유리
- **속성 상성 없음**: 물리/마법은 위 방어력 계수 차이만 존재, 원소 상성표는 없음
- **스킬배율**: 기본공격 = 1.0, 스킬은 0.8~2.0
- **랜덤편차**: 0.9 ~ 1.1 (±10%)
- **최소 데미지 보장**: 결과가 1 미만이면 1로 고정

### 치명타

```
치명타 확률 = 기본 5% + (속도 × 0.2%) + 치명타스탯%
치명타 데미지 = 최종 데미지 × 1.5
```

- 속도와 치명타 스탯 모두 치명타 확률에 기여
- 무기/방어구에 치명타 능력치가 붙으면 직접적으로 확률 상승

### 선/후공 판정

```
유저 속도 > 몬스터 속도 → 유저 선공
유저 속도 = 몬스터 속도 → 50% 확률
유저 속도 < 몬스터 속도 → 몬스터 선공
```

### 계산 예시

```
유저: 공격력 30, 속도 20, 치명타 스탯 10
      스킬 "강타" (배율 1.5)
몬스터: 방어력 20

기본 데미지 = 30 × 1.5 - 20 × 0.5 = 35
랜덤 적용 = 35 × 1.05 (예시) = 36
치명타 확률 = 5% + (20 × 0.2) + 10 = 19%
치명타 발생 시 = 36 × 1.5 = 54
```

**마법 데미지 예시** (지팡이 + 파이어볼)

```
유저: 유효 공격력 30, 스킬 "파이어볼" (배율 1.9)
몬스터: 방어력 20

마법 데미지 = 30 × 1.9 - 20 × 0.2 = 57 - 4 = 53
(같은 조건 물리라면 57 - 10 = 47 → 고방어 몬스터에 마법이 유리)
랜덤 적용 = 53 × 0.95 (예시) = 50
```

### 공식 요약

| 항목 | 공식 |
|------|------|
| 물리 데미지 | `공격력 × 스킬배율 - 방어력 × 0.5` |
| 마법 데미지 | `공격력 × 스킬배율 - 방어력 × 0.2` |
| 랜덤 편차 | `× (0.9~1.1)` |
| 최소 데미지 | 1 |
| 치명타 확률 | `5% + 속도×0.2% + 치명타스탯%` |
| 치명타 배율 | `× 1.5` |
| 선공 판정 | 속도 비교 |
| 도망 성공 | 50% 고정 |

## 몬스터 / 보스 AI (MVP)

MVP의 몬스터와 보스는 **매 턴 기본공격만** 수행한다 (스킬·상태이상·특수 패턴 없음).

- 몬스터 데미지 = 자신의 **공격력**을 기준으로 **±10% 랜덤**을 적용해 산출
- 데미지 계산은 플레이어 공격과 **동일한 공식**을 사용한다 (스킬배율 1.0)
- **몬스터도 고유 `damageType`을 가진다**: 물리 몬스터는 물리 공식(방어 계수 0.5), 마법 몬스터(마법사류)는 마법 공식(방어 계수 0.2)을 적용한다 → 마법 몬스터는 플레이어 방어력을 덜 받아 위협적이다 (`generations/gen1/monsters.md`)

```
물리 몬스터 데미지 = (몬스터 공격력 × 1.0 - 플레이어 방어력 × 0.5) × 랜덤편차(0.9~1.1)
마법 몬스터 데미지 = (몬스터 공격력 × 1.0 - 플레이어 방어력 × 0.2) × 랜덤편차(0.9~1.1)
```

- **랜덤편차 0.9~1.1** = "공격력 ±10% 랜덤 데미지"
- 최소 데미지 보장(1 미만이면 1)은 플레이어 공격과 동일
- 보스도 동일하게 기본공격만 하며, 공격력·HP 수치 자체가 높아 위협이 된다 (별도 AI 분기 없음)

> 스킬 사용·페이즈 전환 등 보스 전용 패턴은 이후 확장 단계에서 추가.
