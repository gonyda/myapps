# MyRPG 개발 TODO

### 추후 기능

**1. 게임 내 시간 시스템 (In-Game Time)**
- **현실 시간 $\rightarrow$ 인게임 시간 전환**:
  - 현재 실제 시계(`Clock`) 기반으로 동작하는 시간 시스템을 가상 인게임 시간으로 변경.
  - 캐릭터 진행 상태(`CharacterProgress`)에 인게임 시각(예: Day N, 00:00~23:59)을 저장/영속화.
- **시간 경과 규칙**:
  - 맵 노드 이동 1회마다 일정 인게임 시간 흐름 (예: 30분~1시간 소모).
  - 단, 전투 중에는 시간이 흐르지 않음.
- **시간대별 환경 및 테마 연동**:
  - 시간대(새벽 / 아침 / 낮 / 노을 / 밤)에 따른 `AmbienceService` 상황 멘트 및 UI/분위기 테마 전환.
  - 필드 보스 랜덤 등장 및 특정 이벤트와 시간대 연계.

**2. 밤 시간대 기습 확률 대폭 상향 (야간 위험도 증대)**
- **기존 기습 확률**: 전 맵 기본 5% (`MonsterEncounterService.PREEMPTIVE_STRIKE_PERCENT = 5`).
- **밤 시간대(예: 20:00 ~ 06:00)**:
  - 몬스터 기습(선공) 확률을 **50%**로 대폭 상향.
  - 야간 이동 시 위험도를 극대화하여 "밤길 탐험의 긴장감" 부여.

**3. 캠프파이어 & 야영 시스템 (Campfire & Rest)**
- **기능 개요**:
  - 필드 노드에서 `[모닥불 피우기]` 상호작용을 통해 캠프파이어 설치.
- **효과 및 메카닉**:
  - **밤 시간 스킵**: 위험한 밤 시간을 안전하게 넘겨 아침(06:00 등)으로 시간 진행.
  - **휴식 및 회복**: HP / MP / 스태미나 / 부상 회복.
  - **마비노기식 감성**: 모닥불 주변에서 음식 나눠먹기, 쉐어링 버프, 휴식 음악/연출 등 마비노기식 여행 낭만 구현 (추후 아이템/요리와 연계).

**4. 보스 랜덤 등장 (필드)**
- 보스를 마을/던전이 아닌 **필드에 랜덤(랜덤 시간 + 랜덤 필드)** 으로 등장시키는 기능.
- **`Monster` sealed 승격 불필요** — 랜덤 등장은 데이터 형태가 아니라 **스폰 시점/위치(배치)** 문제. 보스 데이터 필드는 일반 몬스터와 동일하다.
- 필요한 것: 스폰 설정(대상 보스, 등장 확률/주기, 대상 필드 풀, 유지/소멸 시간) + 동적 배치 서비스 + **런타임 스폰 상태**(정적 로스터와 달리 상태 보관 필요, `map.json` 정적 매핑과 별개 경로).
- sealed는 보스가 **구조적으로 다른 필드**(페이즈별 스탯, 인레이지 타이머, 쫄몹 소환 등)를 가질 때만 검토 — 그런 요구가 실제로 생기면 그때 승격.
- **시간 시스템과 연계**: 특정 인게임 시간(예: 심야 00:00, 붉은 달 등)에만 등장하는 필드 네임드/보스 이벤트 구성 가능.
