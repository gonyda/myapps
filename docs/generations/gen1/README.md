# 세대 1 (스타터) — 레벨 1~10

현재 개발 범위. 세대 1은 스타터 콘텐츠로, 레벨 밴드 1~10에 대응한다.

## 구성 요약

| 항목 | 내용 |
|------|------|
| 레벨 밴드 | 1 ~ 10 |
| 던전 | 숲(1), 광산(5), 탑(10) — 3개, 각 5스테이지 |
| 무기 | 타입별 1종 (총 6종) — `weapons.md` |
| 방어구 | 부위별 1종 (총 4종) — `armors.md` |
| 스킬 | 무기 타입별 1종 (총 6종) — `skills.md` |
| 일반 몬스터 | 6종 | 
| 보스 | 3종 |
| 소모품 | HP/MP 포션 (세대 무관 공통, `systems/shop.md`) |

- 세 던전 모두 **세대1 장비 전체(무기 6 + 방어구 4)를 드랍**한다. 던전 간 차이는 등급 확률(`gradeChance`)과 `itemLevel`뿐이다. (모델: `systems/farming.md`)

## 던전별 등급 확률 (gradeChance)

상위 던전일수록 고등급 확률이 높다. (합 = 1.0)

| 던전(권장Lv) | COMMON | UNCOMMON | RARE | EPIC | LEGENDARY |
|------|------|------|------|------|------|
| 숲(1) | 0.700 | 0.220 | 0.060 | 0.018 | 0.002 |
| 광산(5) | 0.550 | 0.280 | 0.120 | 0.040 | 0.010 |
| 탑(10) | 0.400 | 0.300 | 0.180 | 0.090 | 0.030 |
