# 기본 시스템 상세 (basic-system)

> MyRPG 로드맵 1순위. 레벨(현재/누적) · 레벨업 스탯 성장 · 경험치 곡선 · 사망 패널티 · 환생 · 정보 팝업 환생 UI · 환생 시 재능 선택 훅을 정의한다.
>
> 이 문서는 스펙(`.kiro/specs/myrpg/003-...`) 작성 전 설계 초안이며, "확인 필요 / 결정 사항"의 미결 항목이 확정되면 스펙으로 옮긴다.

## 현재 구현 상태 (baseline)

스펙 001에서 아래 데이터 모델은 이미 존재하나, **행동 로직(경험치 획득·레벨업·환생)은 전혀 구현되어 있지 않다.**

| 요소 | 현재 상태 | 이 문서에서 |
|---|---|---|
| `CharacterProgress.currentLevel` / `accumulatedLevel` | 필드 존재, 신규 1/1 | 레벨업·환생 규칙 부여 |
| `CharacterProgress.experience` | 필드 존재, 신규 0 | 획득/차감/곡선 부여 |
| `Stats(str, dex, intelligence, critical, defense)` | `@Embeddable record`, 전부 `int` | 성장 규칙 + `critical` 타입 변경 필요 |
| `Vital(current, max)` | HP/MP/Stamina 각 100/100 | 레벨업 시 최대치 증가 |
| `ExperiencePolicy.requiredForNext(level)` | `level * 100L` 선형 placeholder | 실제 곡선으로 교체 |

---

## 1. 레벨 시스템

- **현재레벨(currentLevel)**: 범위 `1 ~ 100`. 100이 최대 레벨.
- **누적레벨(accumulatedLevel)**: 모든 생애(환생 포함)에서 도달한 레벨의 총합. 환생해도 초기화되지 않고 계속 누적된다. 신규 생성 시 `1`.
- **레벨업 시**: `currentLevel += 1`, `accumulatedLevel += 1`.
- **환생 시**: `currentLevel`을 1로 리셋하고 `accumulatedLevel += 1` (새 생애가 레벨 1로 시작하는 것을 반영).
  - 예: 레벨 1에서 환생 → 누적레벨 `1 + 1 = 2`.
  - 예: 레벨 50까지 올린 뒤 환생 → 그 생애 레벨업으로 이미 누적 50, 환생 시 +1 → `51`.
- **실시간 갱신**: 누적레벨은 레벨업이 발생하는 즉시 증가시키고(환생 시점에 몰아서 정산하지 않음), 해당 턴 종료 시 저장하며 정보 팝업 표시에 곧바로 반영한다. 즉 누적레벨은 항상 `현재레벨 + 과거 생애 도달 레벨의 합`과 일치한다.
- **최대레벨(100) 도달 시**: 더 이상 경험치를 획득하지 않고 레벨업도 발생하지 않는다. 경험치 게이지는 **가득 찬 상태**로 렌더링하고, 게이지 위 수치 오버레이는 `MAX`로 표기한다.

## 2. 스탯 기본값 (기존 유지)

신규 캐릭터 초기 스탯은 현재 `Stats.createDefault()` / `Vital.createDefault()`와 동일하게 유지한다.

| 스탯 | 초기값 |
|---|---|
| STR | 10 |
| DEX | 10 |
| INT | 10 |
| Critical | 5% |
| DEF | 5 |
| HP | 100 / 100 |
| MP | 100 / 100 |
| Stamina | 100 / 100 |

## 3. 레벨업 스탯 성장

레벨업 1회마다 아래 값만큼 성장한다.

| 스탯 | 레벨업당 증가 | Lv100 도달 시(누적 99회) |
|---|---|---|
| STR | +3 | 10 + 297 = 307 |
| DEX | +3 | 10 + 297 = 307 |
| INT | +3 | 10 + 297 = 307 |
| Critical | +0.3% | 5 + 29.7 = 34.7% |
| DEF | +1 | 5 + 99 = 104 |
| HP(최대) | +10 | 100 + 990 = 1090 |
| MP(최대) | +10 | 100 + 990 = 1090 |
| Stamina(최대) | +10 | 100 + 990 = 1090 |

### 3.1 스탯 계산 방식 (레벨 파생 = 저장하지 않고 계산)

레벨업 스탯은 **저장하지 않고 현재레벨로부터 계산**하는 것을 권장한다. 이렇게 하면 환생 시 `currentLevel`을 1로 되돌리는 것만으로 레벨 파생 스탯이 자동으로 초기화된다(별도 초기화 로직 불필요).

```
표시 스탯 = 기본값 + 레벨파생분 + 스킬랭크업분
레벨파생분(stat) = 레벨업당증가(stat) × (currentLevel - 1)
```

- HP/MP/Stamina 최대치도 동일하게 `100 + 10 × (currentLevel - 1) + 스킬랭크업분`으로 계산한다.
- **스킬 랭크업분**은 별도로 저장하며(3순위 스킬 시스템에서 채움), 환생 시 유지된다(§6.2 참고). 현 시점에는 값이 0이지만, 모델은 처음부터 이 항목을 분리해 두어야 한다.

## 4. 경험치 시스템

### 4.1 필요경험치 곡선

`ExperiencePolicy.requiredForNext(level)`을 아래 곡선으로 교체한다. 레벨 `L`에서 `L+1`로 가는 데 필요한 경험치:

```
requiredForNext(L) = BASE_EXP × L²
BASE_EXP = 100  (튜닝 가능 상수)
```

| L (현재레벨) | 다음 레벨 필요 경험치 |
|---|---|
| 1 | 100 |
| 2 | 400 |
| 5 | 2,500 |
| 10 | 10,000 |
| 25 | 62,500 |
| 50 | 250,000 |
| 75 | 562,500 |
| 99 | 980,100 |
| 100 | — (최대, 레벨업 없음) |

- 곡선은 **단조 증가**하고 정수(`long`)로 계산 가능하다.
- `BASE_EXP`와 지수(2)는 튜닝 가능하며, **경험치 획득처인 전투(7순위)가 도입된 뒤 최종 밸런싱**한다. 그 전까지는 이 곡선을 기준값으로 사용한다.
- **최대레벨(100)** 에서는 경험치를 누적하지 않는다(초과분 폐기). 게이지는 가득 찬 상태로 두고 수치 오버레이는 `MAX`로 표기한다.

### 4.2 경험치 획득

- 경험치 획득의 주 원천은 **전투(7순위)** 이며, 본 시스템은 "경험치 증가 → 필요치 도달 시 레벨업" 규칙만 정의한다.
- 한 번의 획득으로 필요치를 초과하면 남는 경험치를 다음 레벨로 이월하며, 필요 시 **연속 레벨업**을 처리한다. (최대레벨 도달 시 초과분은 버린다)
- **임시 테스트 버튼**: 전투가 없는 현 시점 검증을 위해 좌측 사이드바 정보 버튼 아래에 `[경험치 업]`(경험치 +500 고정), `[경험치 다운]`(사망 패널티 로직 실행) 버튼을 둔다. 전투 도입 시 대체되는 개발용 수단이다.

## 5. 사망 패널티

- 캐릭터 사망 시 **현재 경험치 게이지를 10%p(현재 레벨 필요치의 10%)만큼 차감**한다.
  ```
  차감량       = floor(requiredForNext(currentLevel) × 0.10)
  경험치_after = max(0, 경험치_before - 차감량)
  ```
- 예시: `requiredForNext = 100`이고 현재 경험치가 `23/100`(23%)이면, 10(=100×10%)을 빼서 `13/100`(13%)이 된다.
- **레벨은 내려가지 않는다.** 차감 후 경험치가 음수가 되어도 이전 레벨로 넘어가지 않고 `0`으로 고정한다. 예: `5/100` → `0/100`.
- 스탯·레벨·누적레벨·스킬 등 다른 값은 사망으로 변하지 않는다.
- **최대레벨(100)** 에서는 경험치를 누적하지 않으므로(게이지 `MAX` 고정) 사망 패널티가 경험치에 영향을 주지 않는다.

## 6. 환생 시스템

### 6.1 환생 가능 조건

- **직전 환생 후 현실시간 24시간 경과** — 이것이 **유일한** 조건이다.
- **현재레벨과 무관**하다. 레벨이 몇이든(1이어도) 24시간 조건만 충족하면 환생할 수 있다.
- 한 번도 환생한 적이 없는 캐릭터는 직전 환생 기록이 없으므로 **즉시 환생 가능**하다.

### 6.2 환생 효과

| 대상 | 처리 |
|---|---|
| 현재레벨 | 1로 초기화 |
| 경험치 | 0으로 초기화 |
| 레벨업으로 얻은 스탯 | 초기화 (레벨=1이 되므로 자동) |
| 스킬 랭크업으로 얻은 스탯 | **유지** |
| 누적레벨 | **유지 + 1** (초기화하지 않고, 새 생애 레벨 1 반영으로 `+1`) |
| HP/MP/Stamina | 최대치가 기본값 기준으로 재계산되고 현재값은 최대치로 회복 |
| 재능 | 환생 시 **재선택** (§7, talent-system.md 연계) |

### 6.3 쿨다운 처리

- 마지막 환생 시각(`lastRebirthAt`)을 저장하고, 값이 있으면 `now >= lastRebirthAt + 24h`일 때만 환생을 허용한다.
- `lastRebirthAt`이 없으면(첫 환생) 시간 제한 없이 허용한다.
- 환생 불가 시 남은 쿨다운을 안내한다.

## 7. 재능 선택

- **신규 캐릭터 생성 시 기본 재능은 `근접전투`** 이다.
- 재능 목록은 **`근접전투` / `활` / `마법`** 3종이 확정이며(추가 여부는 재능 시스템에서 논의), 캐릭터는 **환생할 때 재능을 재선택**할 수 있다.
- 재능의 효과·랭크업 기여 등 상세 메커니즘은 **재능 시스템(2순위, `talent-system.md`)** 에서 정의한다. 본 문서는 아래 두 연계 지점(hook)만 명시한다.
  1. 캐릭터 생성 시 기본 재능 = `근접전투` 부여.
  2. 환생 플로우 안에 재능 재선택 단계 포함(환생 확정 → 재능 선택 → 상태 초기화(§6.2) 순서).
- 재능은 캐릭터 진행상황에 저장되며 환생으로 초기화되지 않고 선택값으로 교체된다.

> **스펙 003 범위 결정**: 첫 구현(스펙 `003-character-progression-and-rebirth`)에서는 **재능 선택 UI를 생략**하고, 신규 생성·환생 모두 재능을 `근접전투(MELEE)`로 고정한다. 3종 중 택1하는 재능 선택 기능은 재능 시스템(2순위)에서 추가한다.

## 8. 정보 팝업 UI

정보 팝업(좌측 정보 팝업, 001의 `panel-popup.html` 정보 영역)은 상/중/하 3구역으로 구성한다.

- **상단**: 닉네임, 현재레벨, 누적레벨, 현재 재능, HP/MP/Stamina(`현재값 / 최대값`)
- **중앙**: STR, DEX, INT, Critical(소수 1자리 %), DEF — 각 스탯을 `본체 (+스킬 랭크업분)` 형식으로 표기한다(예: `STR 23 (+11)`). 본체 = 기본값 + 레벨 파생분, 괄호 = 스킬 랭크업분(현재 0, 스킬 시스템에서 채움). 스킬 스탯은 본체 수치에 포함하지 않는다.
- **하단**: [환생하기] 버튼, 환생 후 경과시간
  - [환생하기]는 환생 가능(§6.1, 24시간 경과 또는 첫 환생)일 때만 활성. 24시간 미만이면 비활성(disabled).
  - 첫 환생(환생 기록 없음)이면 경과시간 자리에 "환생 기록 없음"을 표시한다.
  - 활성 버튼 클릭 → `환생을 진행하시겠습니까?` 확인 팝업 → 확인 시 환생 처리(재능은 근접전투 고정, §7 스펙 003 범위 결정).

- 좌측 사이드바 정보 버튼 아래에는 개발용 테스트 버튼 `[경험치 업]`/`[경험치 다운]`(§4.2)을 둔다.
- 장비/인벤토리/스킬 팝업은 본 문서/스펙 범위 밖(10순위 `ui-left-popup.md`)이다.

| 대상 | 변경 |

| `CharacterProgress` | 선택한 재능 저장 필드 추가 (신규 생성 시 `근접전투`, 환생 시 재선택) |
| `Stats` | `critical`을 **0.1% 단위 정수**로 저장(기본 50 = 5.0%, 레벨업당 +3 = +0.3%, 표시값 = 저장값 ÷ 10) |
| `ExperiencePolicy` | `requiredForNext`를 §4.1 곡선으로 교체 |
| 스탯 계산 | 레벨 파생 스탯은 저장하지 않고 `currentLevel` 기반 계산으로 전환(§3.1) |

## 10. 결정 사항 (확정)

- **환생 조건**: 오직 "직전 환생 후 24시간 경과". 현재레벨과 무관(§6.1). 첫 환생은 즉시 가능.
- **누적레벨**: 모든 생애 도달 레벨의 총합. 레벨업 즉시 +1(실시간 갱신·저장·표시), 환생 시 +1(새 생애 레벨 1). 레벨 1 환생 → 2(§1, §6.2).
- **사망 패널티**: 현재 레벨 필요치의 10%(게이지 10%p) 차감, 최소 0, 레벨 다운 없음(§5). 예 `23/100` → `13/100`.
- **레벨업 시 회복**: HP/MP/Stamina 현재값을 **풀 회복**(현재값 = 최대치)(§6.2 및 아래).
- **신규 캐릭터 기본 재능**: `근접전투`. 재능 목록 `근접전투/활/마법` 3종 확정(§7).
- **최대레벨(100) 게이지**: 가득 찬 상태 + 수치 오버레이 `MAX`(§1, §4.1).
- **`critical` 저장 타입**: 0.1% 단위 정수(§9).
- **경험치 곡선**: §4.1 문서안(`100 × L²`) 사용. 전투(7순위) 도입 후 밸런싱.

### 잔여 의존성 (다른 스펙에서 확정)

- **재능 메커니즘**: 재능별 효과·보너스·랭크업 기여는 `talent-system.md`(2순위)에서 정의.
- **스킬 랭크업 스탯**: 환생 시 유지되는 스킬 스탯 보너스의 구체 계산·저장은 `skill-system.md`(3순위)에서 정의(현 시점 값 0).
- **정보 팝업 레이아웃**: [환생하기] 버튼 외 표시 항목 배치는 `ui-left-popup.md`(10순위)에서 확정.

> **레벨업 시 회복 규칙**: 레벨업으로 HP/MP/Stamina 최대치가 +10 되며, 이때 현재값을 최대치로 채워 **풀 회복**한다.
