# 013 액티브 전조 반응 전투 시스템 (Requirements)

## 1. 개요 및 배경

현재 MyRPG의 전투 시스템은 몬스터 AI가 매 턴 1/3 무작위(일반 34%, 강공격 33%, 방어 33%)로 행동하며 플레이어에게 사전 정보가 전혀 주어지지 않는 '맹목적 가위바위보' 구조였다. 이로 인해 플레이어는 몬스터의 행동을 예측할 수 없어 일반 공격(베기)이나 디펜스를 무지성으로 반복 클릭하는 단조로운 플레이에 갇혀 있었다.

또한, 턴제 방식에서 단순히 정적인 전조(텍스트)만 제공할 경우 시간제한이 없어 '단순 짝 맞추기 게임'으로 전락할 위험이 있다.

본 스펙은 다음과 같은 핵심 목표를 달성한다:
1. **2단계 턴 라이프사이클 (대치 ⏸️ ↔ 공방 ⚡)**: 
   - **대치 페이즈 (시간 완전 정지)**: 턴 사이에 시간에 쫓기지 않고 포션 복용, 장비 스왑, 도망, 로그 확인을 할 수 있는 전략적 정비 시간 제공.
   - **공방 페이즈 (1.0~1.5초 실시간 피지컬)**: `[⚔️ 공방 개시]` 클릭 즉시 직관적인 몬스터 전조 뱃지와 함께 실시간 카운트다운 타이머가 작동하여, 찰나의 순간에 상성 스킬을 선택하는 짜릿한 피지컬 반응 손맛 제공.
2. **1레벨 상위 몬스터 공략 가능성**: 플레이어의 뛰어난 눈썰미와 반사신경(피지컬) 및 자원 관리를 통해 1레벨 캐릭터도 상위 몬스터를 공략할 수 있는 기량 개입(Player Skill)의 여지 마련.

## 2. 기능 요구사항

### 2.1. 2단계 턴 라이프사이클 구조 (대치 ⏸️ ↔ 공방 ⚡)

#### [1단계] 대치 페이즈 (Standby Phase - 시간 완전 정지 ⏸️)
- **화면 및 상태 연출**:
  - 몬스터 정보창에 `[ 대치 중 ⏸️ ]` 상태 표시.
  - 타이머 게이지는 멈춰 있으며 작동하지 않음.
  - 스킬 버튼 영역은 비활성화(대기 상태)되며, 중앙에 **`[⚔️ 공방 개시]`** 버튼이 활성화됨.
- **가능한 플레이어 행동 (자유로운 정비)**:
  - **포션 복용**: 인벤토리 팝업을 열어 HP, MP, 스태미나 포션을 복용하여 자원을 회복할 수 있음.
  - **장비 교체**: 인벤토리에서 무기(검/활/완드) 및 방어구(방패/갑옷)를 자유롭게 탈착/교체할 수 있음.
  - **로그/스탯 확인**: 이전 턴의 전투 결과 및 몬스터 HP를 여유롭게 검토.
  - **도망 시도 (`flee`)**: 대치 페이즈에서만 `[도망]` 버튼을 누를 수 있음 (2.4절 참조).

#### [2단계] 액티브 공방 페이즈 (Active Clash Phase - 1.0~1.5초 실시간 피지컬 ⚡)
- **진입 트리거**:
  - 플레이어가 `[⚔️ 공방 개시]` 버튼을 클릭하는 즉시 공방 페이즈로 전환됨.
- **공방 페이즈 연출 및 동작**:
  - 몬스터가 준비한 행동의 **전조 뱃지(B안)**가 크게 표시됨.
  - **실시간 카운트다운 타이머 게이지**(CSS transition)가 실시간으로 줄어듦.
  - 플레이어의 착용 무기 기준 전투 스킬 버튼들이 즉시 활성화됨.
- **스킬별 전역 공통 시전 시간 (모든 몬스터 동일 SSOT)**:
  - ⚡ **일반공격 (`NORMAL`)**: **`1.0초`** (초고속 속공 ➡️ 빠른 디펜스/카운터 반응 요구)
  - 💥 **강공격 (`HEAVY`)**: **`1.5초`** (차징 강타 ➡️ 베기 캔슬 or 카운터 여유)
  - 🛡️ **방어태세 (`DEFENSE`)**: **`1.5초`** (방어 ➡️ 스매시 방어파괴 여유)
- **공방 해결 후 복귀**:
  - 플레이어가 시간 내 스킬을 클릭하거나 타임아웃이 발생하면 턴 결과가 해결되어 전투 로그가 갱신되고, **즉시 다시 1단계(대치 페이즈, 시간 정지)**로 복귀함.

### 2.2. 전조 연출 디자인 (B안: 초심플 직관형 Visual Badge)

몬스터별로 텍스트를 개별 작성하지 않고, **0.1초 만에 눈으로 식별 가능한 직관적인 상태 뱃지와 게이지**로 공통 렌더링한다.

1. **⚡ 일반공격 태세 (`NORMAL`, 1.0초)**:
   - 시각 뱃지: `[ ⚡ 일반공격 태세 ]` (Amber/노란색 네온 강조)
   - 타이머 바: 1.0초 실시간 게이지 감소
2. **💥 강공격 차징 중 (`HEAVY`, 1.5초)**:
   - 시각 뱃지: `[ 💥 강공격 차징 중! ]` (Red/크림슨 펄스 강조)
   - 타이머 바: 1.5초 실시간 게이지 감소
3. **🛡️ 방어 태세 (`DEFENSE`, 1.5초)**:
   - 시각 뱃지: `[ 🛡️ 방어 태세 ]` (Cyan/푸른색 방패 뱃지 강조)
   - 타이머 바: 1.5초 실시간 게이지 감소

### 2.3. 상성 공방 결과 및 타임아웃 판정 규칙

1. **시간 내 유효 스킬 입력 성공 시 (가위바위보 상성 해결)**:
   - **몬스터 강공격 (`HEAVY`) 대비**:
     - 플레이어 `NORMAL (베기)` ➡️ **선제 캔슬 타격 적중** (플레이어 0 피격, 몬스터 베기 데미지 피격).
     - 플레이어 `DEFENSE (카운터)` ➡️ **160% 카운터 반격 적중** (플레이어 0 피격, 몬스터 반격 데미지 피격).
     - 플레이어 `DEFENSE (디펜스)` ➡️ **방어 관통 피격** (스매시 풀 데미지 피격).
   - **몬스터 일반공격 (`NORMAL`) 대비**:
     - 플레이어 `DEFENSE (디펜스)` ➡️ **100% 완전 방어** (플레이어 0 피격, 몬스터 0 피해).
     - 플레이어 `DEFENSE (카운터)` ➡️ **160% 카운터 반격 적중** (플레이어 0 피격, 몬스터 반격 데미지 피격).
     - 플레이어 `NORMAL (베기)` ➡️ **동일 공격 무승부** (양측 상성 계수 0.5 피해 교환).
     - 플레이어 `HEAVY (스매시)` ➡️ **스매시 시전 중 피격/캔슬** (플레이어 일반공격 데미지 피격, 몬스터 0 피해).
   - **몬스터 방어태세 (`DEFENSE`) 대비**:
     - 플레이어 `HEAVY (스매시)` ➡️ **방어 관통 가드 브레이크** (몬스터 스매시 풀 데미지 피격, 플레이어 0 피격).
     - 플레이어 `NORMAL (베기)` ➡️ **칼 튕김/막힘** (몬스터 0 피해, 플레이어 0 피격).
     - 플레이어 `DEFENSE (카운터/디펜스)` ➡️ **교착** (양측 0 피해, 카운터 사용 시 스태미나 8 소모).

2. **타임아웃 (제한 시간 초과) 발생 시**:
   - 플레이어가 1.0초/1.5초 내에 아무 스킬도 누르지 못한 경우:
     - 몬스터의 의도가 **100% 확정 성공**하여 플레이어는 **무방비 피격**을 입는다.
     - 몬스터 `NORMAL` ➡️ 플레이어 일반공격 100% 피격.
     - 몬스터 `HEAVY` ➡️ 플레이어 강공격(스매시) 100% 풀 피격.
     - 몬스터 `DEFENSE` ➡️ 몬스터가 방어만 했으므로 양측 0 피해 교착.
   - 타임아웃 로그 출력 후 다시 대치 페이즈로 복귀.

### 2.4. 예외 상황 및 특수 메카닉 처리

1. **자원 부족 (스태미나/마나 부족) 처리**:
   - 스킬 사용 시 불필요한 브라우저 `alert` 팝업창은 일체 띄우지 않는다 (`docs/todo.md` 3번 요구사항 연계).
   - 자원이 부족한 스킬 버튼을 누를 경우, 턴을 소모하거나 피격되지 않고 **하단 활동 로그(`action-log`)에만 "스태미나(또는 마나)가 부족합니다."** 메시지를 기록한다.
   - 타이머는 멈추지 않고 계속 흐르며, 플레이어는 남은 시간 내에 자원이 충분한 다른 유효 스킬을 빠르게 다시 선택할 수 있다.

2. **도망 (`flee`) 메카닉**:
   - `[도망]` 버튼은 **대치(시간 정지) 페이즈에서만 활성화**된다 (공방 중 도망 불가).
   - **50% 확률 성공**: 즉시 전투 종료 및 이전 맵 화면으로 복귀.
   - **50% 확률 실패**: 몬스터의 **`일반 공격 (NORMAL)` 1회 확정 피격**을 받은 뒤, 전투를 종료하지 않고 다시 대치 페이즈로 복귀한다.

3. **궁수 1턴 선제 사격 (`Bow First Strike`)**:
   - 활 착용 시 전투 1턴은 몬스터 전조 없이 `[공방 개시]`를 누르면 스킬 버튼들이 활성화된다.
   - 플레이어가 **원하는 활 스킬(`조준 사격`, `매그넘 샷`, `애로우 리볼버`)을 직접 선택**하여 누르면, 100% 확정 선제 사격(몬스터 반격 0)이 발동한다.
   - 2턴부터는 정상적인 대치 ⏸️ ↔ 공방 ⚡ 사이클로 진입한다.

4. **법사 마법 캐스팅 실패 (`Magic Cast Failure`)**:
   - 마법 공격 스킬 사용 시 **10% 확률로 캐스팅 실패**가 발생한다.
   - 캐스팅 실패 시 마법이 불발되어 몬스터에게 0 피해를 주며, 몬스터가 공격 중이었다면 플레이어가 피격을 입는다.

## 3. 비기능 및 품질 요구사항

1. **품질 5대 가드레일 준수**:
   - **Spotless**: Java 포맷팅 자동 교정 (`mvn spotless:apply`).
   - **Error Prone**: 정적 결함 컴파일 타임 차단.
   - **ArchUnit**: 패키지 계층 및 아키텍처 규칙 검증.
   - **JaCoCo**: 단위/통합 테스트 코드 커버리지 80% 이상 달성.
   - **PMD & CPD**: 복잡도, 안티패턴 및 중복 코드 검증.
2. **밸런스 스크립트 검증**:
   - `tools/balance/verify_skill.py` 검증 통과 (16키 완비, 단조 비감소).
3. **CodeGraph 동기화**:
   - 코드 변경 후 `codegraph sync` 완료.
