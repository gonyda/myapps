# New Module Guard

## 신규 모듈 추가 시 필수 질문

사용자가 새 모듈 추가를 요청하면 (예: "새 모듈 만들어줘", "모듈 추가해줘", "새 애플리케이션 추가" 등), **코드 작성 전에 반드시** 아래 질문을 먼저 해야 합니다.

### 필수 확인 사항

모듈 생성 전에 다음 두 가지를 사용자에게 질문하세요:

1. **모듈 유형**: 웹(Web) 모듈인지, 배치(Batch) 모듈인지
   - **Web**: REST API / 웹 서비스 → `spring-boot-starter-web` 사용
   - **Batch**: 배치 처리 작업 → `spring-boot-starter-batch` 사용

2. **모듈명**: `my` 접두사를 포함한 모듈명 (예: `myreceiver`, `myjob`)
   - 이미 사용자가 이름을 제시했다면 확인만 해도 됨

### 규칙

- 모듈 유형을 확인하기 전에는 `pom.xml`, 디렉터리, 소스 파일을 **절대 생성하지 않습니다**
- 사용자가 유형을 명시한 경우 (예: "웹 모듈 추가해줘")에는 재확인 없이 진행해도 됩니다
- 자세한 모듈 생성 절차는 `module-template.md`를 참고하세요
