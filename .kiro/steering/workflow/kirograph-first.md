# KiroGraph 우선 원칙

## 규칙: 기존 소스 분석은 반드시 KiroGraph MCP를 최우선으로 사용합니다

기존 코드의 구조·동작·호출관계·심볼 파악은 파일을 직접 read하지 말고
**무조건 KiroGraph MCP를 먼저** 사용합니다 (`kirograph_context`/`search`/
`node`/`callers`/`impact` 등). 이 규칙은 서브에이전트 컨텍스트 수집 시에도
동일하게 적용됩니다 (컨텍스트 수집은 예외가 아님).

## 이유
- **크레딧 절약**: 직접 파일 읽기는 토큰 소모가 크므로, 그래프로 필요한
  부분만 정밀하게 가져와 비용을 최소화합니다.

## 직접 read가 허용되는 경우 (폐쇄 목록 — 이 외 전부 금지)
1. KiroGraph로 조회했으나 결과가 불충분한 경우 (최후의 수단)
2. **이번 세션에서 방금 수정된 파일** — 인덱스는 agentStop에 동기화되므로
   세션 중엔 stale일 수 있음 → 이 경우만 직접 read 정당
3. 소스가 아닌 파일 (`.json`, `.yml`, `.xml`, `pom.xml` 등)

## 적용 범위
- 기존 소스 확인/분석 모든 작업에 예외 없이 적용됩니다.
