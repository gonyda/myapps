# CodeGraph 우선 원칙

## 규칙: 기존 소스 분석은 반드시 CodeGraph MCP를 최우선으로 사용합니다

**기존 소스 코드를 확인하거나 분석해야 하는 작업이라면, 파일을 직접 `read`하지 말고 무조건 CodeGraph MCP를 먼저 활용합니다.**

- 직접 파일 읽기(`read_file`, `read_files`, `read_code` 등)를 최우선 수단으로 사용하지 않습니다
- 기존 코드의 구조, 동작, 호출 관계, 특정 심볼(클래스/메서드/함수) 파악은 **CodeGraph MCP를 최우선으로 사용**합니다

## 이유

- **크레딧 절약**: 직접 파일을 읽는 방식은 크레딧 소모가 크므로, CodeGraph MCP를 통해 필요한 소스만 정밀하게 가져와 비용을 최소화합니다

## 예외: 직접 소스 읽기 (최후의 수단)

- CodeGraph MCP로 소스를 분석했으나 결과가 미비하여 작업에 필요한 정보를 충분히 얻지 못한 경우에 한해, **최후의 방법으로** 파일을 직접 읽습니다
- 직접 소스를 읽는 것은 어디까지나 마지막 수단이며, CodeGraph MCP 활용을 먼저 시도한 뒤에만 사용합니다

## 적용 범위

- 이 규칙은 기존 소스 코드를 확인/분석하는 모든 작업에 예외 없이 적용됩니다
