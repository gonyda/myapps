# New Module Guard

## 신규 모듈 추가 시 필수 질문

사용자가 새 모듈 추가를 요청하면 (예: "새 모듈 만들어줘", "모듈 추가해줘", "새 애플리케이션 추가" 등), **코드 작성 전에 반드시** 아래 두 가지를 확인합니다.

1. **모듈 유형**: Web(REST API) 또는 Batch(배치 처리)
2. **모듈명**: `my` 접두사 포함 (예: `myreceiver`, `myjob`)
   - 사용자가 이미 이름을 제시한 경우 확인만 해도 됨

### 규칙

- 모듈 유형 확인 전에는 `pom.xml`, 디렉터리, 소스 파일을 **절대 생성하지 않습니다**
- 사용자가 유형을 명시한 경우 (예: "웹 모듈 추가해줘")에는 재확인 없이 진행해도 됩니다
- 상세 생성 절차는 #[[file:.kiro/steering/module/module-template.md]] 참고
