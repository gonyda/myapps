# MyRPG 데이터 밸런스 설계 가이드

`item.json` · `monster.json` · `skill.json` 에 **아이템 / 몬스터 / 스킬을 추가·수정**할 때
밸런스를 해치지 않도록 지켜야 할 데이터 설계 기준이다. 새 데이터를 넣기 전 이 문서를 기준선으로 삼는다.

> 데미지 공식은 아래 **§0**에 전부 정리한다(이 문서만으로 데이터 밸런싱이 가능하도록 self-contained).

---

## 0. 핵심 원칙 (반드시 이해하고 시작)

전투 데미지는 **감산형 + 최소 1** 이다. 스킬은 **히트당 배율**(`multiplierByRank`)을 `hitCount`번 적용해 합산한다. 최종 데미지는 아래 순서로 계산한다:

```
공격력   = round(주스탯 × 재능계수)                       // 재능계수: 근접 1.0 / 활 0.85 / 마법 1.2

[스킬 hitCount 만큼 아래를 반복하여 합산]
  기본피해(히트) = max(1, floor(공격력 × 히트당배율% / 100) − 대상.defense)
  보정피해(히트) = 기본피해 × 상성계수 × (크리티컬 ? 1.5 : 1)
  히트피해      = max(1, round(보정피해 × rand(0.90 ~ 1.10)))   // 히트마다 독립 편차
최종피해 = Σ 히트피해                                       // hitCount번 합산
```

- **상성계수**(가위바위보 결과): 승 1.0 / 무승부 0.5 / 방어당함 `(1 − blockRate)` / 관통패 0.0.
- **크리티컬**: `random.nextInt(1000) < (캐릭터 critical + 스킬 critBonus)`(0.1% 단위) 판정 시 **×1.5**. 공격·반격·무승부 **모든 결과**에 적용. **다단 스킬은 히트마다 독립 판정**한다.
- **몬스터 공격 배율**: 몬스터는 스킬이 없어 행동별 상수 배율을 쓴다 — **일반 100% / 강 150%**(공격력 = `attackPower`). 몬스터는 항상 단일 히트(`hitCount` 1, `critBonus` 0).
- **다단(`hitCount` ≥ 2)의 함의**: 방어력이 **히트마다 차감**되므로 **고방어 대상에 급격히 약해지고**(예: 3타 스킬은 방어를 3번 뺌), 크리·편차가 히트별로 독립 발생해 **평균화(안정)**된다. 단일 히트는 방어를 1번만 빼 관통에 유리하고 편차·크리가 all-or-nothing(버스트).

여기서 파생되는 3대 밸런스 규칙:

1. **자동 레벨 스케일링이 없다.** 몬스터 세기는 시스템이 올려주지 않는다. `monster.json`에 값을 직접 authoring한 만큼만 강해진다.
2. **공격력이 상대 방어를 못 넘으면 전부 "1뎀"** 이 된다(무의미). 그래서 **공격 스탯은 항상 그 구간 상대 방어보다 위**여야 한다.
3. **비율(%)로 표현된 값은 전 레벨 자동 스케일**되고(경감률·크리티컬·스킬 배율·몬스터 방어 상수), **정액 값은 레벨에 맞춰 수동 조정**해야 한다(무기 스탯 보너스·몬스터 attackPower/defense/maxHp).

> **데미지 편차**: 최종 데미지엔 상성·크리티컬 계산 후 **±10% 랜덤 편차**가 붙는다 → 데이터는 **평균값 기준**으로 밸런싱하고, "정확히 N턴에 처치" 같은 아슬아슬한 컷에 의존하지 말 것.

## 1. 플레이어 성장 기준선 (`StatProgression`)

몬스터·아이템을 설계할 때 "이 레벨 플레이어는 얼마나 세냐"의 기준.

| 항목 | 산출식 | Lv1 | Lv10 | Lv30 | Lv50 |
|---|---|---|---|---|---|
| 주스탯(STR/DEX/INT) | 10 + 3×(lv−1) `+재능 주스탯 보너스` | 10 | 37 | 97 | 157 |
| DEF | 5 + 1×(lv−1) `+장비` | 5 | 14 | 34 | 54 |
| HP | 100 + 10×(lv−1) `+재능 HP 보너스` | 100 | 190 | 390 | 590 |
| 크리티컬 | 50 + 3×(lv−1) (0.1% 단위) | 5.0% | 7.7% | 13.7% | 19.7% |

- **공격력 = 주스탯 × 재능계수** (근접 1.0 / 활 0.85 / 마법 1.2). 여기에 스킬 배율(%)이 곱해진다.
- 위 표는 **장비·재능 주스탯 보너스 제외한 하한**이다. 실제 플레이어는 장비 DEF·주스탯 보너스로 더 높다 → 몬스터 스탯은 이 하한보다 **여유 있게** 위로 잡는다.

## 2. 아이템 (`item.json`)

### 무기 (`type: weapon`)
- 데미지는 무기가 직접 주지 않고 **주스탯 보너스(`bonuses`)로 공격력에 기여**한다.
- **초보자용 장비 = 밸런스 기준선(baseline)**. 신규 무기는 아래 초보자 티어 대비 상대 위치를 맞춘다.

  | 무기 | kind | 보너스 | 손 |
  |---|---|---|---|
  | 초보자용 한손검 | `one_handed_sword` | STR +5 | 한손(방패 가능) |
  | 초보자용 양손검 | `two_handed_sword` | STR +10 | 양손(방패 불가) |
  | 초보자용 완드 | `wand` | INT +5 | 한손(방패 가능) |
  | 초보자용 스태프 | `staff` | INT +10 | 양손(방패 불가) |
  | 초보자용 활 | `bow` | DEX +10, CRITICAL +10(=1%) | 양손(방패 불가) |

- 무기의 주스탯은 재능에 맞춘다(근접=STR / 활=DEX / 마법=INT). **활은 크리티컬 보너스**로 "활=크리티컬↑" 특성을 무기에서 부여한다(활 재능만 크리티컬 스탯을 무기로 받는다).
- **양손 무기(양손검·활·스태프)** 는 방패와 동시 착용 불가(슬롯 상성, `requiredSlots = {MAIN_HAND, OFF_HAND}`). 한손 무기(한손검·완드)는 방패 병용 가능.
- `maxDurability`: 초보자 장비 20 고정. 공격 턴당 0.2 감소(100턴 = 0). 상위 티어는 값을 키워 교체 주기를 늘린다.

### 방어구 (`type: armor`)
- **초보자용 장비 = 밸런스 기준선(baseline)**:

  | 방어구 | kind | 슬롯 | DEF |
  |---|---|---|---|
  | 초보자용 방패 | `shield` | OFF_HAND | +5 |
  | 초보자용 갑옷 | `armor_body` | BODY | +5 |
  | 초보자용 투구 | `helmet` | HEAD | +3 |
  | 초보자용 장갑 | `gloves` | HANDS | +2 |
  | 초보자용 부츠 | `boots` | FEET | +2 |

  → 초보자 풀세트 합계 **DEF +17**(방패 착용 시). 신규 방어구는 이 티어 대비 상대 위치를 맞춘다.
- DEF는 정액 감산이라 **과도하면 몬스터 공격을 통째로 씹는다** — 신규 방어구 DEF는 해당 티어 몬스터 attackPower를 완전 무효화하지 않는 선.
- 슬롯별 유일 착용(같은 슬롯끼리 스왑). 새 방어구는 슬롯(kind)에 맞춰 추가.

### 포션 (`type: potion`)
- `healHp`, `buyPrice`. 기준선: `hp_potion_30` = 30 회복 / 50골드. 회복량 대비 가격을 비례시킨다.

### 판매가·구매가
- 판매가 = `baseValue(옵션) + 총보너스포인트 × WEIGHT` (모든 보너스 스탯 동일 가중치). `WEIGHT`·비율·구매가 실제 값은 **7순위(상점)에서 확정** — 그 전까지 임시.
- 인챈트(`ENCHANT`)는 스펙 미확정 → 임의 추가 금지.

## 3. 몬스터 (`monster.json`)

### 필드와 기준선(너구리 = Lv1 최약체)
```
level, maxHp, attackPower, defense, critical(0.1% 단위),
experience, goldDrop{min,max}, itemDrops[...],
defenseBlockRate(기본 40), defenseCounterRate(기본 30)   // 생략 시 전역 기본
```
너구리 기준: `Lv1 / HP45 / ATK42 / DEF3 / crit30(3.0%) / exp22 / gold6~16` — 초보 풀장비(유효 DEF ~22)와 8~9턴 접전(플레이어 HP 70% 이상 유지 가능).

### 밸런스 규칙 (가장 중요)
- **attackPower > 그 구간 플레이어 DEF**(장비 포함 추정치) 로 잡는다. 안 그러면 그 몬스터의 모든 공격이 1뎀이 된다. (몬스터 강공격 턴은 배율 **150%**라 순간 피해가 1.5배 — §0 참고.)
- **maxHp = 플레이어가 그 레벨에 넣는 1타 × (원하는 처치 턴 수)**. 일반 몬스터 3~5턴, 보스 10턴+ 정도를 목표로 역산.
- `defense`: 플레이어 공격력을 다 씹지 않는 선(정액). 플레이어 1타를 반 정도로 깎고 싶으면 그만큼만.
- `critical`: 0.1% 단위. 일반 몬스터 낮게(10~50 = 1~5%), 보스만 소폭 상향.
- `experience` · `goldDrop`: 체감 난이도(HP × 위협도)에 비례. 약한 몬스터에 과한 보상 금지.

### 방어(DEFENSE) 상수
- 몬스터는 스킬이 없어 방어 시 **경감률/반격율 상수**를 쓴다. 일반 몬스터 **경감 40% / 반격 30%(×attackPower)**, **보스 60% / 50%**.
- `monster.json`의 `defenseBlockRate`/`defenseCounterRate`로 몬스터별 오버라이드(생략 시 전역 기본). **둘 다 %라 레벨 무관 자동 스케일** — 별도 조정 불필요.
- 반격율은 **일반공격 배율(100%)보다 낮게** 유지(방어가 최고 딜이 되는 역전 방지).

### 스탯 스케일링 규칙 (실측 앵커 기반)

기준은 **플레이어 유효 DEF(기본 + 장비)** 이지 base DEF가 아니다. Lv1 초보 장비 착용 시 유효 DEF ~15(base 5 + 방패 5 + 갑옷 5).

- **Lv1 앵커(너구리)**: 초보 풀장비 유효 DEF ~22 → 몬스터 **ATK ~42, HP ~45, DEF ~3** 이면 8~9턴 접전(플레이어 HP 70% 이상 유지). "초보가 편하게 배우는" 체감. (한손검+방패+갑옷만 착용=DEF 15면 좀 더 아프게 맞음.)
- **스케일링 비율(상위 레벨에 유지)**:
  - 몬스터 `attackPower` ≈ **그 구간 플레이어 유효 DEF의 2~2.5배** (정액 감산+최소1을 뚫고 실피해를 주려면).
  - 몬스터 `maxHp` ≈ **플레이어 1타의 4~6배** (원하는 처치 턴 수).
  - 몬스터 `defense`는 플레이어 1타를 다 씹지 않는 선(낮게).
- 플레이어 유효 DEF는 레벨(+1/lv)·장비로 오르므로, 신규 고렙 몬스터는 그 구간 유효 DEF를 추정해 위 비율로 ATK/HP를 authoring한다. (자동 스케일링 없음 — 데이터로 직접.)

### 보스
- attackPower·maxHp를 크게, `defenseBlockRate`/`defenseCounterRate` 상향(60/50). 인챈트 아이템 드랍은 인챈트 스펙 확정 후 투입.

## 4. 스킬 (`skill.json`)

### 공통 규칙
- `type`: `NORMAL`(일반) / `HEAVY`(강) / `DEFENSE`(방어). `talent`: `MELEE` / `ARCHERY` / `MAGIC` / `COMMON`(방어).
- **랭크 맵은 16키(F → MASTER) 전부**, **단조 비감소**여야 한다(카탈로그 로드 테스트가 강제). 하나라도 빠지거나 감소하면 로딩/테스트 실패.
- `resourceCost`: 근접/활 = 스태미나, 마법 = MP 소모(스킬이 정의). 기준선: NORMAL 7 / HEAVY 10 / DEFENSE 4. 다단 스킬은 +1~2 가산 가능(연타 대가).
- 딜 스킬 필드: `multiplierByRank`(**1히트당** 배율) + `hitCount`(타격 횟수, 기본 1) + `critBonus`(크리 확률 가산, 0.1% 단위, 기본 0).

### 딜 스킬 2축 설계 (배율 하나만으로 차별화 금지)
공격 스킬은 방어 스킬(경감↔반격)과 같은 철학으로 **두 축의 트레이드오프**로 성격을 나눈다. 배율만 다르게 하면 상위호환/복제품이 되므로 금지.

- **축 A — `hitCount`(연타 수)**: 단일(1) = 방어 1회 차감·버스트·고방어 관통 / 다단(2~4) = 방어 N회 차감·편차 평균화(안정)·저방어 학살. **다단은 총배율을 단일보다 살짝 위로** 올려 방어 다중 차감을 보상하되, 고방어 앞에서 자연히 폭락하게 둔다.
- **축 B — `critBonus`(크리 특화)**: 표준(0) / 크리특화(양수). 크리를 얹으면 **기본 배율을 소폭 낮춰** 대가를 치른다(크리 안 터지면 손해, 터지면 폭발). **상한 +100(=+10%p)** — 매그넘 샷이 상한선. 이 상한을 넘기지 말 것.

`multiplierByRank`는 **1히트당 배율**이다. 총 배율 ≈ 히트당 배율 × `hitCount`. 다단 스킬은 히트당 배율을 낮게 쪼갠다.

### 딜 스킬 밴드 & 재능별 정체성

- **NORMAL 단일 밴드**: F 90 → MASTER 170 (기본 딜).
- **HEAVY 단일 밴드**: F 130 → MASTER 250 (스매시·파이어볼트). 활 최상위 `매그넘 샷`은 F 140 → MASTER 260.
- **다단 밴드(히트당)**: 총 배율이 단일 NORMAL보다 살짝 위가 되도록 쪼갠다 — 3타는 히트당 F 35 → 65(총 105→195), 4타는 히트당 F 27 → 50(총 108→200).

| 재능 | 스킬 | type | hitCount | critBonus | 배율(1히트/총) | 정체성 |
|---|---|---|---|---|---|---|
| MELEE | `slash`(베기, **기본**) | NORMAL | 1 | 0 | F90→170 | 올라운더 기준점. 방어 관통 무난 |
| MELEE | `windmill`(윈드밀) | NORMAL | 3 | 0 | F35→65 (총 105→195) | 저방어 학살 + 안정 꾸준딜. 고방어엔 손해 |
| MELEE | `smash`(스매시) | HEAVY | 1 | **80(+8%p)** | F130→250 | 단일 초강타 버스트. 크리 시 폭발 |
| ARCHERY | `aimed_shot`(조준 사격, **기본**) | NORMAL | 1 | 0 | F90→170 | 정직한 단발 기본 |
| ARCHERY | `arrow_revolver`(리볼버) | NORMAL | 4 | 0 | F27→50 (총 108→200) | 연사 초안정딜. 낮은 계수를 다단으로 안정화 |
| ARCHERY | `magnum_shot`(매그넘 샷) | HEAVY | 1 | **100(+10%p)** | F140→260 | 단발 최고 화력 + 크리 상한. 원거리 저격 |
| MAGIC | `mana_bolt`(마나 볼트, **기본**) | NORMAL | 1 | 0 | F90→170 | 무속성 무난 기본(계수 1.2로 이미 강함) |
| MAGIC | `icebolt`(아이스볼트) | NORMAL | 3 | 0 | F35→65 (총 105→195) | 게임 내 최고 안정딜(다단+무크리). 저방어 강 |
| MAGIC | `firebolt`(파이어볼트) | HEAVY | 1 | 0 | F130→250 | 최고 순간 깡뎀(크리 없이 계수 1.2로 폭발) |

- **재능별 축 강조 차이**:
  - **근접(계수 1.0)**: 균형형. 크리특화는 `smash`(HEAVY)에만. HP 탱커라 지속력이 강점.
  - **활(계수 0.85·크리↑ 재능·1턴 선제)**: **크리 지향**. 크리특화는 `magnum_shot`에 몰아준다(상한 +10%p). 기본·다단은 표준.
  - **마법(계수 1.2·캐스팅 실패 10%)**: **깡뎀 지향, 크리 안 씀**(모든 마법 스킬 `critBonus` 0). 계수 1.2가 이미 최고 평균 딜을 주고, 상방은 크리가 아닌 높은 배율·계수로 낸다. 리스크는 캐스팅 실패 10%.
- **원칙**: 같은 재능 내 HEAVY > NORMAL. 신규 딜 스킬은 위 밴드 안에서 두 축의 위치를 정한다(밴드 밖 과도한 값 금지).
- 재능계수(활 0.85 / 마법 1.2)가 최종 데미지에 곱해지므로, **배율만 보고 세다고 판단하지 말 것**. 마법은 배율이 같아도 계수로 더 세고 캐스팅 실패 10% 리스크가 있다.

### 방어 스킬(`DEFENSE`, `talent: COMMON`)
방어(DEFENSE) 타입은 상성상 NORMAL을 이기고 HEAVY에 관통당하는 공용 스킬군이다. `blockRateByRank`(경감률 %)와 `counterMultiplierByRank`(반격율 %, ×공격력) 두 맵을 가지며, **경감률↔반격율의 배분**으로 성격을 나눈다. 현재 2종이 있고 신규 캐릭터에 `defense`가 기본 지급된다.

| 스킬 | 성격 | `blockRateByRank`(경감률) | `counterMultiplierByRank`(반격율) |
|---|---|---|---|
| `defense`(디펜스) | 방어 특화 | F 50 → MASTER 85 (높음) | F 5 → MASTER 10 (낮음) |
| `counter_attack`(카운터 어택) | 반격 특화 | F 5 → MASTER 10 (낮음) | F 15 → MASTER 50 (높음) |

- **반격율 상한 50%**(마스터) — 일반공격(100%)의 절반. 이 상한을 넘기지 말 것(카운터 어택이 상한선).
- **경감↔반격은 트레이드오프로 배분**한다: 디펜스는 경감 높고 반격 최소, 카운터 어택은 그 반대. 두 값을 모두 높게 잡아 만능 스킬을 만들지 말 것.
- 방어는 재능 무관 공통 스킬이라 모든 재능이 사용(마법도 실패 없이 사용 가능). 신규 DEFENSE 스킬은 위 두 성격 축 사이 어딘가에 위치시킨다.

### 재능 특성과의 관계(데이터로 표현되지 않는 규칙, 참고)
- 활: 데미지 계수↓·크리티컬↑, 1턴 선제. 마법: 계수↑·공격 스킬 10% 캐스팅 실패. → 스킬 배율 밴드는 재능 무관 동일하게 두고, 차이는 계수·특성 + 위 2축(`hitCount`/`critBonus`) 배분으로 낸다.

### 향후 확장 축 (신규 스킬 추가 시 참고)
현재 딜 스킬은 3개 레버(배율 / `hitCount` / `critBonus`)로 차별화한다. 스킬이 더 늘어 축이 포화되면 아래 축을 **단계적으로** 도입한다. 무엇을 쓰든 **① 축마다 대가(트레이드오프)를 매기고, ② 기존 축과 역할이 겹치지 않게** 배분한다(예: `hitCount`가 이미 "안정성"을 담당하므로 편차 폭 축은 단일 히트 스킬 전용).

- **부류 1 — 저비용 수치 축 (데이터 + 소폭 엔진 확장)**: 데이터 필드/약간의 계산만으로 가능, 상태 관리 불필요.
  - 자원 효율(`resourceCost` 차등): 저코스트·저배율(스팸) ↔ 고코스트·고배율(버스트).
  - 편차 폭(스킬별 variance): 안정형(0.95~1.05) ↔ 도박형(0.80~1.30). `critBonus`와 별개의 안정↔한탕 축.
  - 방어 관통(penetration): 대상 방어를 flat/% 무시. 고방어·보스 특화.
  - 크리 위력(crit multiplier override): 크리 시 ×1.5 대신 ×2.0 등. 크리 "확률"(`critBonus`)과 구분되는 "위력" 축.
- **부류 2 — 메커니즘 축 (새 서브시스템 필요, 별도 스펙으로 도입)**: 턴에 걸친 상태 관리가 필요, 차별화 폭이 가장 큼.
  - 상태이상(지속): 독/화상(DoT), 둔화, 방어 감소 디버프.
  - 흡혈 / 자원 흡수: 데미지 일부를 HP·MP로 환원(지속력 축).
  - 자기 버프 / 충전: 1턴 충전 후 대폭발, 다음 턴 강화.
  - 조건부 효과: 저HP 처형(배율 급증), 콤보(직전 스킬 연계).
  - 행동 순서: 선제타 / 한 턴 2회 행동(활 선제 로직 재활용).

> 원칙: 새 스킬은 **먼저 기존 3축 + 부류 1**로 채우고, "지속 딜·처형·콤보" 같은 전략적 깊이가 필요할 때만 부류 2를 스펙으로 도입한다.
